# Importação dos resultados municipais de 2024

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Review between task groups with jarvis:codereview.

**Goal:** Trazer a eleição municipal de 2024 do Portal de Dados Abertos do TSE para o Postgres e publicar, por partido, prefeituras conquistadas, eleitorado governado e vereadores eleitos. Isso inclui o contrato `GET /relatorios/dados/municipais-2024`, uma página `/relatorios/municipais-2024` com tabela e barras e a porta Python `AsyncMunicipal2024` (Task 11b), que é o que o Placar (plano 1, fase C) consome (alinhado em 2026-10-22).

**Architecture:** Dois comandos novos no CLI, `download-municipais` e `import-municipais`.
- O download lê só três zips, por uma lista fechada de nomes em pacotes CKAN conhecidos. Reaproveita `RequestsCkanGateway`, `StreamingFileTransfer`, `write_index` e `layout.locate`.
- A importação reaproveita `ZipArchiveReader`, `CsvIndexReader` e `PostgresTabularSink`, que fazem o COPY latin1 `;` para `raw.*` e auditam em `raw.carga`. Usa contratos tabulares novos e só os membros por UF.
- Depois de carregar o `raw`, uma regra pura de domínio escolhe o prefeito vigente de cada município, conta os vereadores eleitos por partido e soma o eleitorado apto. O resultado vai para tabelas `analise.municipal_*`.
- A API lê essas tabelas, aplica uma tabela versionada de equivalência de partidos 2024→2026 e devolve JSON.
- O frontend reaproveita `GraficoPoder`/`layoutBarras` para as barras.

**Tech Stack:** Python 3.14, psycopg 3, Alembic, FastAPI/Pydantic v2, pytest sem Postgres real, ruff, mypy strict. Next.js 16.4, React 19, TypeScript, Tailwind 4, shadcn/ui; verificação com `node --experimental-strip-types`.

**Spec:** Este arquivo. As fontes de dados foram conferidas no CKAN e na CDN em 22/10/2026 (seção "Fontes"). O formato segue `docs/superpowers/plans/2026-10-21-grafico-poder.md`.

Todos os CSV são latin1, separados por `;`, com aspas e cabeçalho. `DT_GERACAO`/`HH_GERACAO` são as duas primeiras colunas. Não há DF nem ZZ: são 26 UFs e 5.569 municípios. Os nomes dos zips não trazem carimbo de geração.

**Os arquivos são regerados todo dia.** Em 22/10/2026, `Last-Modified` era `05:25 GMT` e `DT_GERACAO` era `22/10/2026 02:17:07`. O `consulta_cand_2024` reflete o estado atual das candidaturas:
- Quando um prefeito de 2024 foi cassado, a linha da eleição ordinária passa de `ELEITO` para `NÃO ELEITO`. Exemplo: Guapé/MG, onde DR PEDRO aparece `NÃO ELEITO` em 06/10/2024 e `ELEITO` na suplementar de 06/07/2025.
- As eleições suplementares entram no mesmo arquivo, com `CD_TIPO_ELEICAO=1` e `CD_ELEICAO` próprio (6200, 6237, 6248…), até `DT_ELEICAO=21/06/2026`.
- Há municípios sem nenhum prefeito `ELEITO`, por exemplo Mercês/MG (`SG_UE=48313`) em 22/10/2026.

Colunas usadas:

- `consulta_cand` (50 colunas, ~460 mil linhas nas UFs; MG tem 73.477): `ANO_ELEICAO`, `CD_TIPO_ELEICAO` (2 = ordinária, 1 = suplementar), `NR_TURNO`, `CD_ELEICAO` (619 é o 1º turno, 620 o 2º), `DT_ELEICAO` (`DD/MM/AAAA`), `SG_UF`, `SG_UE` (é o código TSE do município com 5 dígitos), `NM_UE`, `CD_CARGO` (11 = prefeito, 12 = vice, 13 = vereador), `SQ_CANDIDATO`, `NM_URNA_CANDIDATO`, `NR_PARTIDO`, `SG_PARTIDO`, `CD_SIT_TOT_TURNO`/`DS_SIT_TOT_TURNO`. Os códigos de situação são:

  | Código | Situação |

  | 1 | ELEITO |
  | 2 | ELEITO POR QP |
  | 3 | ELEITO POR MÉDIA |
  | 4 | NÃO ELEITO |
  | 5 | SUPLENTE |

"""Correspondência versionada entre os partidos de 2024 e o registro de 2026. A chave é o número."""

from dataclasses import dataclass
from enum import Enum
from typing import Final

VERSAO_EQUIVALENCIA: Final = "2026-10-22"


class Correspondencia(Enum):
    MESMO = "mesmo"
    GRAFIA = "grafia"

    value = require_municipal_year(year).value
    return (
        MunicipalArchive(f"candidatos-{value}", f"consulta_cand_{value}.zip"),
        MunicipalArchive(f"candidatos-{value}", f"consulta_vagas_{value}.zip"),

def municipal_member(member_name: str, year: int) -> MunicipalMember | None:
    found = _MEMBER.fullmatch(PurePosixPath(member_name).name)
    if found is None or int(found.group("ano")) != year:
        return None
    uf = found.group("uf")
    if uf not in MUNICIPAL_UFS:
        return None
    return MunicipalMember(contract=_BY_DATASET[found.group("conjunto")], uf=uf)


def generation_from_csv(member: str, csv_bytes: bytes) -> str:
    """DT_GERACAO e HH_GERACAO da primeira linha, no carimbo DDMMAAAAHHMM de raw.carga."""
    text = io.StringIO(csv_bytes[:_HEAD_BYTES].decode("latin-1"), newline="")
    reader = csv.reader(text, delimiter=";")
    header = next(reader, None)
    first = next(reader, None)
    if header is None or first is None or header[:2] != ["DT_GERACAO", "HH_GERACAO"]:
        raise InvalidGenerationError(member)
    if len(first) < 2:
        raise InvalidGenerationError(member)
    try:
        at = datetime.strptime(f"{first[0]} {first[1]}", "%d/%m/%Y %H:%M:%S")
    except ValueError as exc:
        raise InvalidGenerationError(member) from exc
    return at.strftime("%d%m%Y%H%M")

def build_municipal_results(raw: MunicipalRaw) -> MunicipalBuild:
    names, electorate = _electorate(raw.eleitorado)
    for row in raw.candidatos:
        names.setdefault((row.uf, row.ue), row.nome_ue)
    mayors = _mayors(raw.candidatos)
    seats = _ordinary_seats(raw.vagas)
    council = _council(raw.candidatos)
    elected: Counter[Key] = Counter()
    for item in council:
        elected[(item.uf, item.ue)] += item.eleitos
    municipios = tuple(
        MunicipalityResult(
            uf=key[0],
            ue=key[1],
            nome=names.get(key, ""),
            eleitorado=electorate.get(key, 0),
            vagas_vereador=seats.get(key, 0),
            prefeito=mayors.get(key),
        )
        for key in sorted(set(names) | set(mayors))
    )
    gaps = tuple(
        SeatGap(key[0], key[1], elected.get(key, 0), seats.get(key, 0))
        for key in sorted(set(seats) | set(elected))
        if elected.get(key, 0) != seats.get(key, 0)
    )
    return MunicipalBuild(raw.geracao, municipios, council, gaps)


def _electorate(rows: Iterable[ElectorateRow]) -> tuple[dict[Key, str], dict[Key, int]]:
    names: dict[Key, str] = {}
    totals: dict[Key, int] = {}
    for row in rows:
        if (
            row.cargo != CARGO_PREFEITO
            or row.tipo_eleicao != TIPO_ORDINARIA
            or row.turno != PRIMEIRO_TURNO
        ):
            continue
        key = (row.uf, row.ue)
        names[key] = row.nome_ue
        totals[key] = totals.get(key, 0) + row.aptos
    return names, totals


def _rank(row: CandidateRow) -> tuple[date, int]:
    return (row.data_eleicao, row.turno)


def _mayors(rows: Iterable[CandidateRow]) -> dict[Key, Mayor]:
    grouped: dict[Key, list[CandidateRow]] = {}
    for row in rows:
        if row.cargo == CARGO_PREFEITO and row.situacao == SIT_ELEITO:
            grouped.setdefault((row.uf, row.ue), []).append(row)
    chosen: dict[Key, Mayor] = {}
    for key, linhas in grouped.items():
        top = max(_rank(linha) for linha in linhas)
        winners = {linha.sq_candidato: linha for linha in linhas if _rank(linha) == top}
        if len(winners) != 1:
            raise DuplicateMayorError(*key)
        row = next(iter(winners.values()))
        chosen[key] = Mayor(
            partido=row.partido,
            sigla=row.sigla,
            nome_urna=row.nome_urna,
            sq_candidato=row.sq_candidato,
            data_eleicao=row.data_eleicao,
            turno=row.turno,
            suplementar=row.tipo_eleicao == TIPO_SUPLEMENTAR,
        )
    return chosen


def _ordinary_seats(rows: Iterable[SeatRow]) -> dict[Key, int]:
    seats: dict[Key, int] = {}
    for row in rows:
        if row.cargo == CARGO_VEREADOR and row.tipo_eleicao == TIPO_ORDINARIA:
            key = (row.uf, row.ue)
            seats[key] = max(seats.get(key, 0), row.vagas)
    return seats


def _council(rows: Iterable[CandidateRow]) -> tuple[CouncilSeats, ...]:
    counts: Counter[tuple[str, str, int]] = Counter()
    siglas: dict[tuple[str, str, int], str] = {}
    for row in rows:
        if row.cargo != CARGO_VEREADOR or row.situacao not in SITUACOES_VEREADOR_ELEITO:
            continue
        key = (row.uf, row.ue, row.partido)
        counts[key] += 1
        siglas[key] = min(siglas.get(key, row.sigla), row.sigla)
    return tuple(
        CouncilSeats(uf, ue, partido, siglas[(uf, ue, partido)], counts[(uf, ue, partido)])
        for uf, ue, partido in sorted(counts)
    )

    MissingIndexError,
    SchemaMismatchError,

    ImportCommand,

    MemberOutcome,
    Provenance,

from eleicoes.domain.municipal_contract import (
    MUNICIPAL_COLLECTION,
    generation_from_csv,
    municipal_member,
    require_municipal_year,
)
from eleicoes.ports.archive_reader import ArchiveMember, ArchiveReader
from eleicoes.ports.index_reader import IndexReader
from eleicoes.ports.municipais import MunicipalStore
from eleicoes.ports.tabular_sink import TabularSink


class ImportMunicipalTables:
    def __init__(
        self,
        index: IndexReader,
        archives: ArchiveReader,
        sink: TabularSink,
        store: MunicipalStore,
    ) -> None:
        self._index = index
        self._archives = archives
        self._sink = sink
        self._store = store

    def execute(self, command: ImportCommand) -> MunicipalImportReport:
        year = require_municipal_year(command.year).value
        self._sink.ensure_model()
        try:
            entries = self._index.downloaded(command.origin)
        except MissingIndexError:
            return MunicipalImportReport(ImportReport(()), None)
        outcomes: list[MemberOutcome] = []
        for entry in entries:
            if entry.conjunto == MUNICIPAL_COLLECTION:
                outcomes.extend(self._zip(entry, year))
        tables = ImportReport(tuple(outcomes))
        if tables.count(ImportStatus.FAILED) > 0 or tables.count(ImportStatus.LOADED) == 0:
            return MunicipalImportReport(tables, None)
        built = build_municipal_results(self._store.read_raw(year))
        self._store.save(year, built)
        return MunicipalImportReport(tables, built)

    def close(self) -> None:
        try:
            self._sink.close()
        finally:
            self._store.close()

    def _zip(self, entry: IndexEntry, year: int) -> tuple[MemberOutcome, ...]:
        try:
            opened = self._archives.open(entry.path)
        except ArchiveUnreadableError:
            return (self._mark(entry, entry.arquivo, "", "", ImportStatus.FAILED, ""),)
        try:
            return tuple(self._member(entry, year, member) for member in opened)
        finally:
            opened.close()

    def _member(self, entry: IndexEntry, year: int, member: ArchiveMember) -> MemberOutcome:
        found = municipal_member(member.name, year)
        if found is None:
            return self._mark(entry, member.name, "", "", ImportStatus.IGNORED, "")
        table = found.contract.table
        payload = member.read_bytes()
        try:
            stamp = generation_from_csv(member.name, payload)
        except InvalidGenerationError:
            return self._mark(entry, member.name, "", found.uf, ImportStatus.FAILED, table)
        provenance = _provenance(entry, member.name, stamp, found.uf)
        try:
            linhas = self._sink.replace_member(found.contract, provenance, payload)
        except SchemaMismatchError:
            return self._mark(entry, member.name, stamp, found.uf, ImportStatus.FAILED, table)
        return MemberOutcome(entry.arquivo, member.name, ImportStatus.LOADED, linhas, table)

    def _mark(
        self,
        entry: IndexEntry,
        membro: str,
        stamp: str,
        uf: str,
        status: ImportStatus,
        table: str,
    ) -> MemberOutcome:
        self._sink.record(_provenance(entry, membro, stamp, uf), status, 0, table)
        return MemberOutcome(entry.arquivo, membro, status, 0, table)


def _provenance(entry: IndexEntry, membro: str, stamp: str, uf: str) -> Provenance:
    return Provenance(
        arquivo=entry.arquivo,
        membro=membro,
        geracao=stamp,
        conjunto=entry.conjunto,
        turno=entry.turno,
        uf=uf,
    )

class PostgresMunicipalStore:
    def __init__(self, connect: ConnectionFactory) -> None:
        self._connect = connect
        self._connection: SqlConnection | None = None

    def read_raw(self, year: int) -> MunicipalRaw:
        connection = self._open()
        with connection.transaction(), connection.cursor() as cursor:
            geracao = _generation(_fetch(cursor, _GERACAO, year))
            candidatos = tuple(_candidate(row) for row in _fetch(cursor, _CANDIDATOS, year))
            eleitorado = tuple(_electorate(row) for row in _fetch(cursor, _ELEITORADO, year))
            vagas = tuple(_seat(row) for row in _fetch(cursor, _VAGAS, year))

    def save(self, year: int, built: MunicipalBuild) -> None:
        connection = self._open()
        with connection.transaction(), connection.cursor() as cursor:
            cursor.execute("DELETE FROM analise.municipal_carga WHERE ano = %s", (year,))
            cursor.execute(

                "(ano, geracao, municipios, prefeitos, vereadores, divergencias_vagas) "

                    built.geracao,

                    built.prefeitos,
                    built.vereadores_eleitos,

                ),

            _copy(cursor, "analise.municipal_vereador", _VEREADOR_COLUMNS, _council_rows(year, built))

        if self._connection is not None:
            self._connection.close()
            self._connection = None

def _fetch(cursor: SqlCursor, sql: str, year: int) -> Sequence[Sequence[object]]:
    cursor.execute(sql, (str(year),))
    return cursor.fetchall()


def _text(value: object, field: str) -> str:
    if not isinstance(value, str):
        raise InvalidMunicipalRowError(field)
    return value


def _generation(rows: Sequence[Sequence[object]]) -> str:
    value = rows[0][0] if rows else None
    if not isinstance(value, datetime):
        raise InvalidMunicipalRowError("geracao")
    return value.strftime("%d%m%Y%H%M")

        turno=parse_int(_text(row[5], "nr_turno"), "nr_turno"),
        cargo=parse_int(_text(row[6], "cd_cargo"), "cd_cargo"),
        sq_candidato=_text(row[7], "sq_candidato"),
        nome_urna=_text(row[8], "nm_urna_candidato"),

    )

        nome_ue=_text(row[2], "nm_ue"),

        turno=parse_int(_text(row[4], "nr_turno"), "nr_turno"),
        cargo=parse_int(_text(row[5], "cd_cargo"), "cd_cargo"),
        aptos=parse_int(_text(row[6], "qt_aptos"), "qt_aptos"),

        vagas=parse_int(_text(row[4], "qt_vaga"), "qt_vaga"),
    )


def _mayor_rows(year: int, built: MunicipalBuild) -> list[tuple[object, ...]]:
    rows: list[tuple[object, ...]] = []
    for item in built.municipios:
        mayor = item.prefeito
        base: tuple[object, ...] = (year, item.uf, item.ue, item.nome, item.eleitorado, item.vagas_vereador)
        if mayor is None:
            rows.append((*base, None, None, None, None, None, None, "f"))
            continue
        rows.append(
            (
                *base,
                mayor.partido,
                mayor.sigla,
                mayor.nome_urna,
                mayor.sq_candidato,
                mayor.data_eleicao.isoformat(),
                mayor.turno,
                "t" if mayor.suplementar else "f",
            )
        )
    return rows

    return [
        (year, item.uf, item.ue, item.partido, item.sigla, item.eleitos) for item in built.vereadores
    ]


def _copy(cursor: SqlCursor, table: str, columns: str, rows: list[tuple[object, ...]]) -> None:
    buffer = io.StringIO(newline="")
    writer = csv.writer(buffer, lineterminator="\n")
    for row in rows:
        writer.writerow("" if value is None else value for value in row)
    with cursor.copy(f"COPY {table} ({columns}) FROM STDIN (FORMAT CSV)") as stream:
        stream.write(buffer.getvalue().encode("utf-8"))
